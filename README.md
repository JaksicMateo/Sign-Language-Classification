# Sign Language Classification (with Super-Resolution) 🖐️

This project enhances **sign language images** (dim 28x28) using **CNN** and **ResNet models**, enhanced with **ESRGAN (Enhanced Super Resolution Generative Adversarial Networks)** before classification. Two versions of super-resolution were created: **x2** and **x4**. Results are satisfactory, improving image clarity and classification performance.  

Note: Letters that involve movement (**J**, **Z**) are **excluded** from the dataset.  

---

## ⚡ Features
- Super-resolution enhancement (x2, x4)  
- Classification using **CNN** and **ResNet**  
- Image preprocessing  
- Evaluation with metrics like accuracy, precision, and recall

---

## 🛠️ Technologies Used
- Python
- NumPy, Pandas
